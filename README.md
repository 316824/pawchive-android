# Pawchive 安卓版：GitHub 云端构建

此目录是独立的安卓项目，不会替换 Windows 桌面版。安卓端用 PySide6，APK 在 GitHub Actions 的 Ubuntu 云端运行器上构建，因此不需要本机 WSL2、虚拟机平台或 Android Studio。

## 安卓端功能

- 输入 Pawchive 画师主页链接并按日期排序。
- 可先扫描封面、标题和直链文件类型，再勾选要下载的图集。
- 支持按图集标题分文件夹保存，也支持平铺保存和序号重命名。
- 通过 Android 系统文件夹选择器指定保存位置。
- 下载期间显示单文件进度与日志。

安卓的文件夹选择器会返回系统授权的目录 URI；Qt 的 Android 文件系统支持在已授权目录内创建文件和子文件夹。下载先写入应用临时区，再复制到你选择的文件夹。

## 你需要做的事

1. 将本目录中的**全部内容**复制到你克隆的空仓库根目录。包括隐藏的 `.github` 文件夹。
2. 在 GitHub Desktop 中提交更改并点 **Push origin**。
3. 打开仓库网页的 **Actions**，选择 **Build Pawchive Android APK**，点 **Run workflow**。
4. 等待运行完成，打开该次运行记录，在 **Artifacts** 下载 `PawchiveDownloader-APK`。
5. 解压后将 APK 传到手机并安装。若系统询问是否允许此来源安装应用，请为你用来打开 APK 的文件管理器或浏览器允许安装。

上传的 APK 是首次安装/试用用的调试包。若以后要发布到应用商店或长期给别人分发，再单独制作正式签名版本。

## 如果 Actions 失败

打开失败的运行记录，点开第一个红色步骤，把该步骤最末尾的错误文字发回来即可。不要把 GitHub 密码、访问令牌或验证码发给任何人。
